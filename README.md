## 🚀 Featured projects

### [Stock Dashboard](https://github.com/ch2911/dashboard-project) · [live demo](https://ch2911.github.io/dashboard-project/)
A full-stack stock tracker with a **Next.js (TypeScript)** front end, a **Python Flask** REST API and **Supabase PostgreSQL** with row-level security.
- **342 automated tests** (pytest and Vitest) run on every pull request in GitHub Actions before deploying, and a daily smoke test checks the live site
- A walk-forward backtest of 44,100 forecasts per model across 63 stocks found that neither ARIMA nor gradient-boosted trees beat a no-change forecast, so the app shows a likely-price range instead

### [fileconv](https://github.com/ch2911/fileconv)
An open-source (MIT) **Python** command-line and desktop app that converts images, video, audio and documents on your own device, with tests on Windows, macOS and Linux and automated releases.
